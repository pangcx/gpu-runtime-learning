# 03 - 神经网络核心概念

## 核心结论

- 神经网络 = 输入数据 → 多层数学变换 → 输出结果；训练 = 不断调整参数让输出更准
- **全连接层**：每个输入连所有输出，本质是矩阵乘法；适合表格数据和最终分类层
- **卷积层**：用小滤波器在图像上滑动，共享参数，参数量少 100 倍且保留空间结构
- **激活函数**：引入非线性，使网络能拟合复杂规律；ReLU 是最常用的（x<0 输出 0，x≥0 原样输出）
- **池化**：2×2 窗口取最大値，尺寸减半；降低计算量 + 扩大感受野 + 位置鲁棒性；没有可学习参数
- **感受野**：每加一层 3×3 卷积，感受野扩大 2（第n层 = (2n+1)×(2n+1)）
- **多个滤波器** 解决“能看到多少种特征”，**多层卷积** 解决“能看多大范围”，两者是正交维度
- 不同位置的信息在全连接层 Flatten 后才真正汇总

---

## ❓ 全连接、卷积、激活函数这些概念是什么？

神经网络本质上就是一个**函数**：

```
输入数据 → [层1] → [层2] → [层3] → 输出结果
```

每一"层"是一种数学变换。训练 = 不断调整变换里的参数，让输出越来越准确。

---

## 全连接层（Linear）

每个输入都连接到每个输出，数学本质是矩阵乘法：

```
输出 = 输入 × 权重矩阵 + 偏置
```

- 适合：表格数据、网络最后的"分类判断"部分
- 缺点：处理图片时参数量爆炸（224×224 图片有 5 万像素）

---

## 激活函数（ReLU、Sigmoid 等）

全连接层只是线性变换，多少层叠加还是线性的，表达能力有限。
激活函数引入**非线性**，让网络能学到更复杂的规律。

**ReLU（最常用）**：
```
x < 0  →  输出 0
x ≥ 0  →  输出 x（原样输出）
```

类比：线性变换只能拟合直线，激活函数让网络可以拟合曲线。

---

## ❓ 好像没有看到卷积层？

在 `train.py` 的 MLP 版本里确实没有卷积层，那是纯全连接网络（MLP），MNIST 这种简单任务全连接就能达到 97%+，适合入门。

`train_cnn.py` 里才有卷积层，可以对比两个版本的准确率差距（~97% vs ~99%）。

---

## ❓ 卷积的思路是把每个滤波器小块作为整体在内部做全连接，不同小块之间再做全连接吗？

**第一部分：对的。**

一个 3×3 滤波器扫到某位置，就是把那 9 个像素做加权求和，确实等价于"9 个输入全连接到 1 个输出"。

**第二部分：不对。**

卷积的核心设计恰恰是：**不同位置之间不连接**。滤波器滑动时用的是**完全相同的一组权重（共享参数）**，每个位置独立计算，互不干扰。

```
位置(0,0) → 输出一个数 ┐
位置(0,1) → 输出一个数 ├── 用的是同一组 9 个权重
位置(1,0) → 输出一个数 ┘
```

**参数量对比**（输入 784，输出 32 通道）：
```
全连接: 784 × 32 = 25,088 个参数
卷积:   3×3 × 32 =    288 个参数  ← 少 100 倍
```

不同位置的信息整合，是在后面**全连接层** Flatten 之后才发生的。

---

## ❓ 特征图（Feature Map）是什么？不同滤波器小块之间是怎么协同互联的？

**特征图**：一个滤波器扫过整张图，每个位置输出一个数，所有数排列成的新"图"。数值含义是"该位置包含该特征的强度"。

用 32 个滤波器 → 得到 32 张特征图，每张描述一种特征（横线/竖线/弧度…）。

**位置间的协同，分三个层次：**

### 第一层：单张特征图内部——靠重叠窗口

相邻位置的卷积窗口有重叠，天然共享信息：

```
原图:  A B C D E
位置1: [A B C]  → out1
位置2:   [B C D]  → out2  ← 共享 B、C
```

### 第二层：跨层整合——靠感受野扩大

每加一层，能"看到"的原图范围扩大：

```
第 1 层：看原图 3×3
第 2 层：看原图 5×5
第 n 层：看原图 (2n+1)×(2n+1)
```

### 第三层：最终汇总——靠全连接层

卷积结束后 Flatten，全连接层把所有位置、所有特征图的信息关联起来，做最终判断。

---

## ❓ 为什么第二层相当于看原图 5×5 的范围？

具体推导：

第一层特征图的每个位置对应原图一个 3×3 区域：
```
特征图(0,0) ← 原图(0,0)~(2,2)
特征图(0,1) ← 原图(0,1)~(2,3)
...
特征图(2,2) ← 原图(2,2)~(4,4)
```

第二层卷积在特征图上做 3×3，位置(0,0)依赖特征图(0,0)~(2,2)这9个位置。
把这9个区域在原图上的覆盖范围合并，就是原图的 `(0,0)~(4,4)` = **5×5**。

规律：每加一层 3×3 卷积，感受野扩大 2。

---

## ❓ 为什么不需要再加 64→128 这样更多层？

**可以加，但对 MNIST 没必要，因为已经够看了。**

两层卷积+池化后，特征图已缩至 5×5，感受野覆盖原图约 20×20，基本覆盖整个手写数字。

继续加层的收益递减。**判断方法**：加层后准确率明显提升就加，微乎其微就不加。

对于更复杂的任务（如 ImageNet 224×224 图片），ResNet 用了 50 层，VGG 用了 16 层，因为图片更大、特征更复杂。

---

## ❓ 池化是什么技术？

**把特征图缩小，只保留最重要的信息。**

最常用：**最大池化（MaxPool2d）**，2×2 窗口取最大值，尺寸减半：

```
┌─1─┬─3─┐     ┌──3──┐
├─5─┼─2─┤  →  └─────┘   取左上 2×2 的最大值 = 5
└───┴───┘
```

三个作用：
1. **降低计算量**：面积缩小 4 倍
2. **位置鲁棒性**：特征稍微偏移也能识别
3. **扩大感受野**：下一层卷积对应原图更大范围

> 池化**没有参数**，是纯规则操作，不需要学习。

---

## ❓ 为什么是 32 个滤波器？

**没有理论推导，32 是经验性的起点。**

几个实际考量：
- MNIST 简单，32 个已足够覆盖所有有意义的局部特征
- 惯例选 **2 的幂次**（16/32/64/128），GPU 计算效率最高
- 越深的层数量越多（深层特征更复杂）
- 通过实验对比来验证，不是靠推算

这种"人工设定、靠实验调整"的参数叫**超参数**，区别于网络自动学习的**参数**（权重值）。

---

## ❓ 为什么要两层（1→32，32→64）而不是一层直接 1→64？

**多个滤波器解决"能看到多少种特征"，多层解决"能看到多大范围"，两者是正交维度。**

一层 1→64，每个输出仍然只看原图 3×3，无论多少个滤波器都改变不了这一点。

特征本身有层次性：
```
第一层：横线、竖线、斜边（简单基础特征）
第二层：弯钩、交叉、封闭圆弧（由基础特征组合而成）
全连接：综合所有特征做最终判断
```

类比：学语言不能跳过"单词"直接从"字母"学"段落"。分层抽象是自然的认知方式。

---

## 完整 CNN 信息流（MNIST 为例）

```
输入图片 [1, 28, 28]
    ↓ Conv2d(1→32, 3×3) + ReLU
[32, 26, 26]  ← 32 种局部特征（边缘/笔画）
    ↓ MaxPool2d(2×2)
[32, 13, 13]
    ↓ Conv2d(32→64, 3×3) + ReLU
[64, 11, 11]  ← 64 种组合特征
    ↓ MaxPool2d(2×2)
[64, 5, 5]    ← 感受野已覆盖原图大部分
    ↓ Flatten
[1600]
    ↓ Linear(1600→128) + ReLU + Dropout
[128]
    ↓ Linear(128→10)
[10]          ← 每个类别的得分
```
