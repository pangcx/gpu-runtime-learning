# 08 - 大语言模型 vs 垂类小模型

## 核心结论

- 垂类小模型：一个模型解一个问题，固定输出格式；LLM：一个模型解所有问题，自由文本输出
- LLM 规模差异极大：参数量千亿级，训练数据几万亿 token，训练成本数千万～数亿美元
- **预训练不需要人工标注**：用"预测下一个词"任务，互联网文本自带标签，吃掉 45TB 原始数据
- **指令微调（SFT）需要少量标注**：几万条高质量指令-回答对，教模型"按指令回答"而非"续写"
- **RLHF** 用人类偏好排序进一步对齐，是 ChatGPT 好用的关键
- 核心洞察：知识在预训练阶段已经压缩进参数，SFT 只是解锁了"对话接口"

---

## ❓ 前面学的这些数据集和训练方案，是不是都是垂类小模型？和 GPT 这样的大语言模型最主要的区别是什么？

**是的，前面都是垂类小模型。**

### 核心区别

| | 垂类小模型 | 大语言模型（LLM）|
|---|---|---|
| 任务范围 | 一个模型解决一个问题 | 一个模型解决所有问题 |
| 输出格式 | 固定（分类标签/数值）| 自由文本 |
| 使用方式 | 专门训练、专门部署 | 描述需求，直接对话 |
| 例子 | MNIST 只能认手写数字 | GPT 可以写代码、翻译、分析 |

### 规模差异

| | 垂类小模型 | GPT 类 LLM |
|---|---|---|
| 参数量 | 几万～几百万 | 几百亿～几万亿 |
| 训练数据 | 几万～几百万条 | 几万亿 token（数百万本书）|
| 训练时间 | 几分钟～几小时 | 几个月，用数千张 GPU |
| 训练成本 | 可忽略 | 数千万～数亿美元 |

---

## ❓ GPT 这样的大语言模型也需要标注数据吗？还是互联网内容就可以作为训练集？

**分三个阶段，标注需求完全不同。**

### 阶段一：预训练（不需要人工标注）

直接喂互联网原始文本（Common Crawl、Wikipedia、书籍、代码…）。

任务是**预测下一个 token**：
```
输入: "今天天气很"  →  目标: "好"
输入: "def add(a, b):"  →  目标: "return a + b"
```

文本自带标签（下一个词就是答案），不需要人工标注。GPT-3 用了约 **45TB 文本**，全部是无监督数据。

**作用**：让模型学会语言规律，把互联网上的人类知识"压缩"进参数。

---

### 阶段二：指令微调 SFT（需要少量人工标注）

用带标注的**指令-回答对**教模型怎么和人对话：
```
指令: "用简单语言解释量子纠缠"
回答: "想象两个粒子……"  ← 人工写的高质量回答
```

数据量小（几万～几十万条），但需要人工，成本高。

**作用**：教模型"按指令回答"而不是"续写文本"。

---

### 阶段三：RLHF——人类反馈强化学习

让标注员对多个回答排序（哪个更好），用偏好信号继续训练：
```
问题: "如何减肥？"
回答A vs 回答B → 人工标注：A > B
```

**作用**：让输出更安全、更有帮助。ChatGPT 之所以"好用"，很大程度来自这一步。

---

## 关键洞察：为什么少量标注数据能改变 LLM 行为

预训练已经把人类几乎所有知识和推理模式"压缩"进了参数。

指令微调只是加了一个**"会话接口"**——让模型知道"你要我回答，不是续写"。

这就是为什么用几万条标注数据就能显著改变模型行为：**知识已经在那里了，只是需要解锁**。
