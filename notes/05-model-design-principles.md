# 05 - 模型设计原则

## 核心结论

- 层数和滤波器数量都是**超参数**，没有公式，靠经验起点 + 实验验证
- 层数原则：从小开始，准确率不够就加，过拟合就减；MNIST 这类简单任务 2~3 层足够
- 滤波器数量选 2 的幂次（16/32/64/128），越深的层数量越多
- **多个滤波器**解决"能看到多少种特征"；**多层卷积**解决"能看到多大范围"，两者是正交维度
- **数据集是核心资产**，比代码更重要，占项目工作量 60~80%；没有数据，网络只是随机参数

---

## ❓ 网络需要多少层，按什么原则设计？为什么不是更多或更少？

**没有固定公式，本质是经验 + 实验。**

通用原则：
- 太少：欠拟合，学不到复杂规律
- 太多：过拟合、训练慢，小数据集适得其反
- MNIST 这种简单任务，1~3 个全连接层就够

每层宽度通常从大到小递减（漏斗形）：
```
784 → 128 → 64 → 10
```
逐步压缩，强迫网络提炼最关键的特征。

**实际工程怎么决定**：从小网络开始，准确率不达标就加层，过拟合就减少或加正则化。反复实验。

---

## ❓ 为什么是 32 个滤波器？

没有理论推导，32 是行业经验起点。详见 [03-neural-network-concepts.md](./03-neural-network-concepts.md)。

## 参数 vs 超参数

| | 参数（Parameter）| 超参数（Hyperparameter）|
|--|--|--|
| 是什么 | 权重、偏置等数值 | 层数、滤波器数、学习率 |
| 如何确定 | 训练**自动学习** | **人工设定**，靠经验和实验 |
| 例子 | 滤波器的 9 个权重值 | 32 个滤波器、lr=0.001 |

---

## MLP vs CNN 对比（MNIST 任务）

| | MLP（全连接）| CNN（卷积）|
|--|--|--|
| 结构 | Flatten + Linear × 3 | Conv × 2 + Linear × 2 |
| 图片处理方式 | 展平成一维，忽略空间结构 | 保留空间结构，局部感知 |
| 参数量 | ~10 万 | ~20 万 |
| MNIST 准确率 | ~97% | ~99% |
| 适合任务 | 表格数据 | 图像数据 |

## ❓ 这个训练程序的开发并不复杂，关键是数据集吗？

**是的，数据集是核心资产，甚至比代码更重要。**

训练本质：用数据告诉网络"什么输入对应什么输出"，网络反复拟合这个规律。没有数据，网络只是一堆随机参数。

实际工程中，数据工作往往占整个项目 **60~80% 的工作量**：
- 收集数据（爬取、采集、购买）
- 清洗数据（去掉错误标注、处理缺失值）
- 标注数据（人工打标签，成本极高）
- 数据增强（旋转、裁剪扩充数量）

MNIST 适合入门正是因为现成、高质量、已标注好。
